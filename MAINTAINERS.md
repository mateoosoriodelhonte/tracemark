# Maintainers

TraceMark is currently maintained by the repository owner,
[@mateoosoriodelhonte](https://github.com/mateoosoriodelhonte).

## Responsibilities

Maintainers are responsible for:

- triaging issues and keeping public reports free of sensitive research or vulnerability details;
- reviewing changes against the privacy, permission, storage, import, and cross-browser contracts;
- requiring evidence proportionate to the risk of a change;
- managing releases, checksums, store-submission material, and release notes;
- coordinating private security reports and publishing fixes without unnecessary disclosure;
- keeping contribution, support, and governance documentation current.

Maintainer status is not a promise of immediate support. Availability, risk, and release readiness
determine response and merge timing.

## Authority

The repository owner currently has final merge, release, and moderation authority. Contributors may
challenge a technical conclusion with evidence, request clarification, or propose a different
design. Final decisions should be documented in the relevant issue or pull request when practical.

## Adding maintainers

A future maintainer should demonstrate sustained, careful contributions across more than one area;
understand TraceMark's local-first and least-privilege boundaries; review without exposing user or
security data; and be willing to maintain both Chrome and Firefox behavior. Repository permissions
should be granted gradually and follow the minimum access needed for the role.

Before adding another release authority, update [GOVERNANCE.md](GOVERNANCE.md) with decision,
quorum, key-person, and succession rules. Offboarding should remove repository and release access
promptly while preserving public attribution for past work.

For contribution routes, see [CONTRIBUTING.md](CONTRIBUTING.md). For support and private-report
routing, see [SUPPORT.md](SUPPORT.md) and [SECURITY.md](SECURITY.md).
