# Use TraceMark in a citation workflow

TraceMark helps retain a quotation and its source, but it is not a citation manager and does not
generate style-specific bibliographies.

## Capture provenance

Select the exact passage on a normal webpage and save it through the toolbar action when you want to
review the title, collection, tags, and note. Record author, publication date, page section, edition,
or access-date information in **My note** when the source page or title does not preserve it.

The saved URL and title identify where the quotation came from, while prefix and suffix support
later exact-text anchoring. Neither field proves authorship, publication status, or source quality.

## Verify before citing

Open the saved source and use **Mark on page** when available. TraceMark marks only one unambiguous
exact match; it refuses missing or changed text. Review the surrounding page manually, confirm the
speaker and claim, and check whether a more stable primary source exists.

For dynamic pages, consider noting the access date and a stable publication identifier. TraceMark
does not archive the webpage itself, so a source can disappear even though the saved quotation and
URL remain in your library.

## Export into writing tools

Use **Download Markdown** to obtain readable quote blocks, source links, dates saved, collections,
tags, and notes. Copy only the material needed into your writing or citation system, then format the
citation according to the required style. Review the export before sharing because it may include
the entire library if no collection filter was active.

Keep a JSON backup separately for recovery; JSON is not intended as polished citation output.
Local AI summaries and explanations should be treated as generated notes, not quoted sources.
