# Getting started with TraceMark

TraceMark is a local-first research library for quotations you save from the web. It keeps the quotation attached to its source URL, page title, and limited surrounding context. Your library lives in the current browser profile; TraceMark has no account, cloud sync, telemetry, or application backend.

## Before you begin

- Install and enable the TraceMark extension in Chrome or Firefox.
- Use a regular web page where browser extensions may access the page. Browser-internal pages, browser store pages, and browser-owned PDF viewers can reject capture.
- Have text on a page that you want to keep as a quotation.

## Save your first quotation

1. Select the exact text on the webpage.
2. Open the TraceMark toolbar action. Review the quotation and source information in the capture view.
3. Optionally choose a collection and add tags or a note.
4. Choose **Save quotation**.

For a fast capture to the default **Inbox**, right-click a selection and choose **Save selection to TraceMark**, or press `Alt+Shift+S`. These two paths save directly instead of opening the review view.

Open **TraceMark Research Library** in Chrome’s side panel or Firefox’s sidebar to see the saved card. It shows the quotation, page title, source host, save date, collection, tags, and any note. The result counter should report the number of saved quotations.

## Build a practical routine

Use Inbox as a landing place for quick captures, then organize later. In the library, choose **Manage collections** to create a named collection. Use **Edit** on a saved quotation to move it to an active collection, enter comma-separated tags, or add a note, then choose **Save changes**.

Search is available from **Search research**. It searches stored quotation text and relevant metadata, including page title, source host, notes, tags, and collection names. You can also narrow visible results with the **Collection** and **Tag** filters. Select **Clear filters** when you want the full library again.

## What to expect when something does not work

If TraceMark says there is no selection, select text again and retry. If it reports that the page cannot be captured, open the content on a normal website instead; protected browser pages cannot be made available by TraceMark.

Capturing and marking rely on a browser-recognized gesture for the active page. Opening the library alone does not grant access to another tab. If your library is empty after saving, use **Search** to refresh it, then check that you are not filtering to another collection or tag.

Your research is not an automatic backup. Once you have useful material, open **Backups** and download a JSON backup; see [Backup and restore](BACKUP_AND_RESTORE.md) for the recovery workflow.
